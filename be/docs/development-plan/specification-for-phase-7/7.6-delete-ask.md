# 7.6 — Xoá `POST /documents/{id}/ask` (giữ feedback + `ask()`)

> Spec cho **agent implement**. 7.5 đã xong: FE chat qua SSE `POST /sessions/{id}/messages?stream=1`. Endpoint tạm Phase 5 `POST /api/documents/{document_id}/ask` **không còn caller** trên FE. 7.6 gỡ HTTP tạm đó khỏi OpenAPI / router.

**Cấm** đụng feedback URL. **Cấm** xoá / đổi chữ ký `ask()` / `ask_for_user()` (eval + session path vẫn cần).

`POST /api/documents/{id}/ask` biến mất; `POST .../ask/{answer_id}/feedback` vẫn 204; `ask()` gọi từ eval vẫn chạy; chat session (JSON + SSE) không đổi.

## 3. Thiết kế code

### 3.1 `documents.py`

Xoá khối `@router.post("/{document_id}/ask" ...)` toàn bộ hàm `ask_document`.

Giữ nguyên khối `@router.post("/{document_id}/ask/{answer_id}/feedback" ...)`.

Cập nhật docstring feedback nếu còn viết `AskResponse.answer_id` — đổi thành `ai_usage_log.id` / `answer_id` từ session `done` / `MessageResponse` (không phụ thuộc class đã xoá).

### 3.2 `schemas/rag.py`

Sau khi xoá route, file chỉ còn (ý):

```text
FeedbackRequest  # is_positive, reason optional
```

Xoá `AskRequest`, `CitationResponse`, `AskResponse` nếu không còn reference trong `be/app/**`.

`MessageCreate` / `MessageCitationResponse` ở `schemas/message.py` **giữ** — chỉ sửa comment “khớp AskRequest / CitationResponse của /ask” thành past tense hoặc bỏ tên class đã xoá (tránh doc sai).

### 3.3 Việc **không** đụng

- `fe/src/services/chatService.js` — URL feedback giữ `/documents/${id}/ask/${answerId}/feedback`
- `sessionService.js` / `ChatPanel.jsx`
- Middleware SSE
- Bảng `answer_feedback` / `ai_usage_log`
