# 7.4 — Judge / output moderation sau `token` + `event: replace`

> Spec cho **agent implement**. 7.3: generate `beta.stream`, SSE `retrieving` → `generating`, **judge vẫn trước `token`**. 7.4 đưa judge + retry + output moderation **ra sau** lần hiện chữ đầu. FE **chưa** đọc SSE (7.5) — JSON mặc định vẫn chờ `done`, user app **không** thấy bản nháp.

Người dùng `curl -N` có thể thấy câu generate rồi bị `replace` trong vài giây. Chấp nhận (input moderation đã chạy). **Cấm** để bản ungrounded / flagged **nằm im** đến `done` rồi lưu DB.

---

## 0. Một câu

SSE: `token` (+ `citation`) ngay sau generate → judge/retry/mod → nếu câu đổi thì `replace` → **chỉ lúc đó** `save_assistant_message` (bản **final**) → `done`. JSON/`ask()` chỉ trả bản đã judge.

## 2. Quyết định đã chốt (retry — đừng để Gemini chọn lại)

| Tình huống | SSE | Lưu DB / `done` |
|---|---|---|
| Generate xong, judge ≥ 0.7, output sạch | `token` + `citation`; **không** `replace` | Đúng câu đó |
| Judge < 0.7, retry ≥ 0.7 | `token` bản 1 + citation; rồi **một** `replace` `{content, citations}` bản 2 | Bản 2 |
| Judge < 0.7, retry vẫn < 0.7 | `token` bản 1; `replace` `REFUSAL_SENTENCE`, `citations: []` | Câu từ chối, không citation |
| Output moderation flagged (sau judge, kể cả sau retry) | `replace` `REFUSAL_SENTENCE`, `citations: []` | Từ chối |
| Input moderation flagged | **Không** generate. `token` = từ chối, không `citation`, không `replace` | Từ chối |

`REFUSAL_SENTENCE` = hằng hiện có trong `rag_service.py`. Không bịa câu khác.

Retry generate: gọi `_generate_structured` như hiện tại, **không** yield `status: generating` lần 2 (FE 7.5 chưa có). Không `event: token` lần 2.

## 3. Thiết kế code

### 3.1 `ask_events` — thêm event `generated`, `result` = final

Sau `_generate_structured` lần 1 + `_log_call("generation")`, **trước** `score_faithfulness`:

```text
yield ("generated", {
    "answer": <render_structured_answer>,
    "citations": <citations_from_structured_answer(structured, chunks)>,  # list[Citation]
    "call_group_id": call_group_id,
})
```

Rồi chạy **nguyên** khối judge + retry + output moderation như hiện tại (đừng mất log `judge` / generation lần 2 / `output_moderation`). Cuối cùng `yield ("result", AnswerResult final)` như 7.3.

Input flagged: **không** `generated`; chỉ `result` từ chối (như 7.3).

`ask()`: vẫn chỉ lấy event `result` — eval **không** thấy bản nháp. Không đổi chữ ký `ask()` / `ask_for_user`.

Payload `generated` không cần đưa `chunks` ra SSE; đủ answer + citations.

### 3.2 `send_message_events`

```text
draft_answer = None
draft_citations = []   # Citation objects hoặc dict đã serialize
result = None

async for event, payload in ask_events(...):
    if event == "status":
        yield status
    elif event == "generated":
        draft_answer = payload["answer"]
        draft_citations = payload["citations"]
        yield ("token", {"delta": draft_answer})
        for c in draft_citations:
            yield ("citation", serialize(c))   # như 7.2: page_number, chunk_id str|null, snippet
    elif event == "result":
        result = payload

# input-mod: không có generated
if draft_answer is None:
    yield ("token", {"delta": result.answer})
    # không citation
else:
    final_answer = result.answer
    final_cits = result.citations
    if final_answer != draft_answer:
        yield ("replace", {
            "content": final_answer,
            "citations": [serialize(c) for c in final_cits],
        })

await log_ai_usage(...)          # từ result FINAL (token/cost đã gồm retry)
await check_cost_budget(...)
save_assistant_message(result.answer, citations=result.citations, ...)  # FINAL
touch_session
yield done  { message_id, answer_id, citations: FINAL serialize }
```

**Không** `save` bản draft. JSON đọc DB lúc `done` = đã judge.

So sánh `final_answer != draft_answer` (string). Refusal vs draft luôn khác → có `replace`.

### 3.3 `replace` JSON

```json
{
  "content": "<câu cuối>",
  "citations": [ { "page_number": int, "chunk_id": str | null, "snippet": str | null } ]
}
```

Refusal: `"citations": []`. 7.5 sẽ **thay** nội dung + danh sách citation trên UI, không append.

### 3.4 Router / FE / middleware

Không đụng. SSE `?stream=1` đã forward mọi `(event, data)` — `replace` tự chảy. JSON bỏ qua `replace` khi iterate.
