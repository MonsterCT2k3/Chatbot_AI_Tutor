# 7.2 — Middleware SSE + `status` (generation vẫn blocking)

> Spec cho **agent implement**. 7.1 đã chốt: generation Groq **không** cho chữ Việt từng từ (JSON một cục). 7.2 **không** gắn `beta.stream`. Việc 7.2: (1) envelope **không nuốt** SSE, (2) POST messages có nhánh SSE, (3) hiện `status` lúc retrieve rồi **một** `token` khi `ask_for_user` xong.

FE **không** đổi. JSON mặc định phải giữ nguyên — app chat đang sống.

---

## 0. Một câu

`curl -N` với `Accept: text/event-stream` thấy `status` rồi `token` rồi `done`; request **không** header đó vẫn JSON envelope như hiện tại.

## 3. Thiết kế code

### 3.1 `app/sse.py`

```text
def format_sse(event: str, data: dict) -> str
# trả "event: {event}\ndata: {json}\n\n"  (json dumps, ensure_ascii=False)
```

Không phụ thuộc FastAPI.

### 3.2 `send_message_events(...)` — async generator

Cùng tham số `send_message(db, session_id, user_id, question)`.

Yield `(event: str, payload: dict)` theo thứ tự:

```
# HTTP-level fail: raise như send_message hiện tại (SessionNotFoundError, …)
# — router bắt TRƯỚC khi StreamingResponse

yield status contextualize     # chỉ nếu history không rỗng, TRƯỚC lệnh LLM rewrite
… contextualize_question …
yield status retrieving
… ask_for_user(...)            # blocking, đủ 6.7 retrieve_question + call_group_id
… save_assistant_message + touch_session …
yield token   { "delta": <full answer string> }
yield citation { page_number, chunk_id, snippet }   # mỗi citation, chunk_id str(uuid)
yield done    { "message_id", "answer_id", "citations": [...] }
```

`answer_id` = `result.call_group_id` (6.6). `message_id` = id tin assistant.

Quota/breaker: `ask_for_user` (và check sớm nếu có history) **raise** như cũ. Generator đã yield `status` rồi thì router phải `yield format_sse("error", {code, message})` rồi dừng — **không** để exception làm 500 JSON đè stream.

### 3.3 `send_message` không copy-paste

```text
send_message(...):
    last = None
    async for event, payload in send_message_events(...):
        if event == "done":
            last = payload
        if event == "error":
            # không xảy ra nếu router mới là chỗ bắt raise —
            # chốt: generator VẪN raise QuotaExceededError / CircuitBreakerOpenError
            # giống send_message hiện tại, để JSON path không đổi.
            raise ...
    reconstruct assistant + citations từ last / query như hiện tại
    return assistant, citations
```

**Chốt raise:** `send_message_events` **raise** `QuotaExceededError` / `CircuitBreakerOpenError` / lỗi LLM giống `send_message` hôm nay. Nhánh JSON router giữ `except` hiện tại.

Nhánh SSE router:

```
try:
    async for event, payload in send_message_events(...):
        yield format_sse(event, payload)
except QuotaExceededError as e:
    yield format_sse("error", {"code": "QUOTA_EXCEEDED", "message": str(e)})
except CircuitBreakerOpenError as e:
    yield format_sse("error", {"code": "CIRCUIT_BREAKER_OPEN", "message": str(e)})
except Exception:
    yield format_sse("error", {"code": "INTERNAL_ERROR", "message": "..."})
```

404/409: **không** vào generator stream — `get_owned_session` / `ensure_document_ready` gọi **trong** generator. Nếu raise trước yield đầu: StreamingResponse vẫn đã mở.

**Chốt để 404 không thành SSE:** router SSE gọi `get_owned_session` + `get_owned_document` + `ensure_document_ready` **trước** `StreamingResponse` (giống `post_chat_message` hiện tại). Generator giả định session/document ready. Trùng check với JSON path là chấp nhận được (rẻ).

Hoặc: generator raise `SessionNotFoundError` trước mọi yield; router SSE bắt các lỗi đó **nếu chưa iterate**. Khó hơn với StreamingResponse (headers đã gửi).

**Bắt buộc:** router SSE validate ownership + ready **trước** `return StreamingResponse`. Copy 5 dòng try/except từ `post_chat_message`.

### 3.4 Router

Cùng `POST /{session_id}/messages`.

```
if _wants_sse(request):
    # 404/409 như trên, rồi
    return StreamingResponse(agen(), media_type="text/event-stream", headers={...})
return MessageResponse.from_model(...)  # như hiện tại
```

`_wants_sse`: `stream` query in `{"1","true","yes"}` (case-insensitive) **hoặc** `"text/event-stream"` in `request.headers.get("accept","")`.

### 3.5 Middleware

Trước dòng `body = b"".join(...)`:

```
if (response.media_type or "").split(";")[0].strip().lower() == "text/event-stream":
    return response
```

Không skip theo path list.
