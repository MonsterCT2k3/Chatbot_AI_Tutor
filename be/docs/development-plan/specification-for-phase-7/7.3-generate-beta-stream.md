# 7.3 — Generate bằng `beta.stream` + `status: generating`

> Spec cho **agent implement**. 7.2 đã xong (JSON mặc định + SSE `status/token/citation/done`). 7.1 chốt API: `client.beta.chat.completions.stream(..., response_format=StructuredAnswer)` → `get_final_completion().parsed`. **Không** C (`create` + `json.loads`). Delta Groq là JSON một cục — **cấm** đẩy JSON đó ra `event: token`.

7.4 mới tách judge ra sau token (`replace`). **7.3 vẫn judge + output moderation TRƯỚC `token`** — JSON FE và SSE cùng chất lượng như hiện tại.

`ask()` / JSON không đổi hợp đồng; SSE thêm `status: generating` **sau** retrieve, **trước** generate; generate dùng `beta.stream` như 7.1; `token.delta` vẫn là câu tiếng Việt đã `render_structured_answer`, không phải JSON thô.

## 3. Thiết kế code

### 3.1 `_generate_structured`

Thay `parse(...)` bằng:

```text
async with call_client.beta.chat.completions.stream(
    model=call_model,
    messages=messages,
    response_format=StructuredAnswer,
) as stream:
    async for _event in stream:
        pass
    final = await stream.get_final_completion()
parsed = final.choices[0].message.parsed
if parsed is None:
    raise ValueError("Groq structured stream returned empty parsed")
return parsed, _usage_from_response(final)
```

Toàn bộ khối trên nằm trong `async def _call():` + `retry_async(_call)` như file hiện tại.

`ask()` **retry faithfulness** vẫn gọi `_generate_structured` — tự được stream API, không viết hàm thứ hai.

### 3.2 Tách `ask_events` — bắt buộc

Không copy-paste `ask()` thành hai bản.

```text
async def ask_events(...) -> AsyncGenerator:
    # toàn bộ thân ask() hiện tại, CHÈN:
    #   yield ("status", {"stage": "retrieving"})  ngay TRƯỚC embed_chunks
    #   (nếu input_flagged: KHÔNG yield retrieving; yield ("result", AnswerResult từ chối); return)
    #   yield ("status", {"stage": "generating"})  ngay TRƯỚC _generate_structured lần 1
    #   (retry generate lần 2: KHÔNG bắt buộc yield generating lần nữa)
    yield ("result", AnswerResult(...))

async def ask(...):
    result = None
    async for event, payload in ask_events(...):
        if event == "result":
            result = payload
    return result
```

`ask_for_user` **giữ**: quota → `ask()` → `log_ai_usage`. Eval và `/ask` không đổi.

### 3.3 `send_message_events`

Sau `save_user` / contextualize (giữ yield `contextualize` như 7.2):

- **Bỏ** `yield retrieving` + `await ask_for_user(...)`.
- Vẫn `check_circuit_breaker` + `check_daily_quota` trước LLM (như hiện tại khi có history; **thêm** check trước `ask_events` cả khi không history — vì không còn `ask_for_user` trên SSE path).
- `async for event, payload in ask_events(db, document_id, question, retrieve_question=..., call_group_id=..., client=..., model=...)`:
  - `status` → `yield` ra SSE
  - `result` → `result = payload`
- `await log_ai_usage(...)` **giống `ask_for_user`** (cùng field, `id=result.call_group_id`). Thiếu bước này = SSE **không** ghi `ai_usage_log` → 6.6/`answer_id` gãy.
- `save_assistant_message` + `touch` + `token` / `citation` / `done` như 7.2.

JSON `send_message` không đổi chữ ký: vẫn for-loop `send_message_events` đến `done`.

Raise `QuotaExceededError` / `CircuitBreakerOpenError` từ generator như 7.2 (JSON router 429/503; SSE router `event: error`).

Không đụng. `?stream=1` / `Accept` như 7.2.
