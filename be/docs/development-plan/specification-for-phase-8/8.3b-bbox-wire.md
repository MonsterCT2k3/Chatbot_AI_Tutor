# 8.3b — Wire bbox: ingest → citation/SSE → overlay rect trên viewer

> Spec cho **agent implement**. Spike **[8.3](8.3-bbox-spike.md)** đã **PASS** với `CHOICE=GO_WIRE`: `pypdfium2` + schema `pdf_user_space` + công thức lật Y sang CSS. 8.1–8.2 giữ overlay **trang** khi không có bbox.

8.3b: điền `document_chunks.bbox` lúc ingest; đưa `bbox` (optional) ra citation SSE + lịch sử; FE vẽ rect khi có. Document/chunk cũ `bbox=null` → UI như 8.2.

## 3. Thiết kế code

### 3.1 `ingestion_service.py` — extract

```text
def build_chunk_bbox(pdf_bytes: bytes, page_number: int, chunk_content: str) -> dict | None:
    # page_number: 1-based
    # Mở PdfDocument (caller có thể mở 1 lần và truyền page/textpage để tránh N lần parse — API nội bộ được phép tối ưu)
    # NEEDLE strategy:
    #   1. normalize_ws(chunk_content)
    #   2. Thử search lần lượt: full string rút gọn (max ~80–120 ký tự đầu có nghĩa),
    #      rồi từng đoạn split theo \n\n / \n (bỏ đoạn quá ngắn < 3 ký tự)
    #   3. textpage.search(query, match_case=False) → get_next(); union get_charbox cho span
    #   4. Mỗi match thành công → 1 rect {x,y,w,h} (bottom-left)
    #   5. Không match cái nào → return None
    #   6. Có ≥1 rect → return schema version 1 với page_width/height từ page.get_size()
```

Tối ưu bắt buộc ở mức worker: **một** `PdfDocument(pdf_bytes)` cho cả document, loop chunk — không mở PDF lại mỗi chunk.

Helper `normalize_ws(s)`: collapse whitespace, strip. Search dùng bản gần với text layer PDF (spike thấy text trang có khoảng trắng đặc thù — nếu full chunk fail, fallback đoạn dòng vẫn được).

### 3.2 `ingestion_worker.py`

Trong vòng tạo `DocumentChunk`, sau khi có `pdf_bytes` và `chunk_rows`:

```text
bbox = build_chunk_bbox(...)  # hoặc batch helper trả list[dict|None] cùng thứ tự
DocumentChunk(..., content=content, embedding=vector, bbox=bbox)
```

Bọc try/except quanh extract toàn trang/chunk: log exception, `bbox=None`.

### 3.3 RAG + session serialize

`Citation`: thêm `bbox: dict | None = None`.

`citations_from_structured_answer`:  
`Citation(..., snippet=..., bbox=chunk.bbox if isinstance(chunk.bbox, dict) else None)`.

`_serialize_citation` / yield `citation` / `replace` / `done`:

```json
{
  "page_number": 22,
  "chunk_id": "...",
  "snippet": "...",
  "bbox": { "version": 1, "coord": "pdf_user_space", "page_width": 960, "page_height": 540, "rects": [...] }
}
```

hoặc `"bbox": null`.

**List messages:** sau khi load `MessageCitation`, collect `chunk_id`s → `select DocumentChunk.id, bbox` → map vào response. `MessageCitationResponse` thêm `bbox: dict | None = None`. `from_model` nhận thêm map hoặc build ở router/service — **một chỗ** gắn bbox, không N+1.

### 3.4 FE

**State** (`LessonWorkspacePage`):

```text
highlightedPage: number | null          // đã có 8.1
highlightedBbox: object | null          // schema bbox hoặc null
```

`revealCitationPage(page, bbox = null)`: set page + highlight page + `setHighlightedBbox(bbox && bbox.rects?.length ? bbox : null)`.

`clearCitationHighlight`: `highlightedPage=null`, `highlightedBbox=null`.

**ChatPanel:**  
`onCitation` / click badge / `onReplace` có citations: gọi `revealCitationPage(page, citation.bbox ?? null)`.  
Auto-jump lần đầu vẫn một lần; citation sau chỉ cập nhật bubble — **click** mới đổi bbox. (Auto-jump dùng bbox của citation **đầu**.)

`mapServerMessage`: giữ `citations` gồm `bbox` nếu server gửi (F5).

**SlideViewer:** props `highlightedPage`, `highlightedBbox`.

Khi `citationActive` và `highlightedBbox?.rects?.length`:

- Trong `.pdf-zoom-box` (cùng hệ `displayWidth` / `displayHeight` đang dùng cho page), map từng rect → `div.citation-bbox-rect` `position:absolute; left/top/width/height` theo công thức §2.9 với `displayWidth` hiện tại (không hard-code 600).
- Style: nền amber bán trong suốt nhẹ (`rgba` alpha thấp), `pointer-events: none`, `z-index` trên canvas chữ nhưng dưới edge-nav nếu cần.
- Chip 8.2 **giữ**.

Khi không có bbox: chỉ viền+chip trang (8.2) — **không** vẽ rect rỗng.

Zoom: `displayWidth` đổi theo zoom → tính lại style từ pdf units (recompute mỗi render) — đúng.

### 3.5 Sơ đồ

```text
ingest pdf_bytes ──pypdfium2──► document_chunks.bbox
ask / citations_from_structured_answer ──► Citation.bbox
SSE citation | listMessages join chunk ──► FE
revealCitationPage(page, bbox)
SlideViewer: page chip (8.2) + rects (8.3b nếu bbox)
```
