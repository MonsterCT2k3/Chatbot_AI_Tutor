# 8.2 — Overlay nhẹ cấp trang trên `SlideViewer` (viền + chip nguồn)

> Spec cho **agent implement**. **8.1 đã xong:** `highlightedPage` + auto-jump + clear; `SlideViewer` đã có class `citation-page-active` và `data-citation-highlight` khi `highlightedPage === pageNumber`. 8.2 chỉ **làm phần nhìn thấy** và kiểm tra viewport — không đổi logic jump/clear.

**Không** bbox vùng chữ. **Không** sửa `be/**`.

---

## 0. Một câu

Khi PDF đang đứng đúng trang được cite, user thấy **viền/glow** quanh khung trang + **chip** `Nguồn · Trang N`; rời trang đó hoặc clear highlight thì mất chỉ báo.

## 3. Thiết kế code

### 3.1 `SlideViewer.jsx`

Trong `.slide-canvas-card` (đã có class điều kiện), thêm chip khi active:

```text
const citationActive = highlightedPage != null && highlightedPage === pageNumber;

<div className={`slide-canvas-card ${citationActive ? 'citation-page-active' : ''}`}
     data-citation-highlight={citationActive ? '1' : '0'}
     ...>
  {citationActive && (
    <div className="citation-source-chip" aria-live="polite">
      Nguồn · Trang {highlightedPage}
    </div>
  )}
  <div className="pdf-scroll-area">...</div>
  ... edge nav buttons ...
</div>
```

Không đổi `goToPage` / zoom / double-buffer.

### 3.2 CSS (`LessonWorkspacePage.css`)

Gợi ý (agent chỉnh số px cho khớp design tokens, không copy cứng nếu token khác tên):

```css
.slide-canvas-card.citation-page-active {
  border-color: /* amber/emerald đậm hơn border thường */;
  box-shadow: /* glow nhẹ */;
}

.citation-source-chip {
  position: absolute;
  top: 10px;
  left: 10px; /* hoặc right — một góc, tránh đè edge-nav */
  z-index: 5;
  pointer-events: none;
  /* font nhỏ, padding chip, radius, màu nền nhạt */
}
```

**Cấm:** `::after` phủ `inset:0` với nền đục che chữ PDF.

Edge-nav vẫn click được. Chip không nằm giữa hai nút trái/phải nếu làm nút khó bấm — ưu tiên **góc trên-trái hoặc trên-phải** cách mép.

### 3.3 Việc **không** đụng lại

- `LessonWorkspacePage` state (trừ phát hiện prop chưa truyền — đã có từ 8.1)
- Auto-jump / SSE handlers
- Backend

### Kết quả đo

Đã xác minh qua build FE (`npm run build`) và test giao diện / render state (`fe/src/scripts/test_8_1_jump.mjs`):

1. **Hiển thị viền active và chip nguồn:**
   - Khi đang ở đúng trang cite (ví dụ trang 22), `.slide-canvas-card` nhận viền hổ phách `--amber-accent` và box-shadow glow nhẹ `0 6px 22px -4px rgba(194, 120, 3, 0.18)`.
   - Chip `📖 Nguồn · Trang 22` xuất hiện ở góc trên-trái (`top: 12px; left: 12px;`) với style nổi bật nhưng không che khuất các nút điều hướng hay thanh công cụ.

2. **Tương tác và an toàn viewport (`pointer-events: none`):**
   - Chip có `pointer-events: none`, không cản trở thao tác cuộn, kéo hoặc tương tác văn bản trên canvas PDF.
   - Khi zoom in / zoom out: chip neo cố định vào góc của `.slide-canvas-card`, không bị dịch chuyển theo CSS scale của canvas layer.
   - Khi thu hẹp chiều rộng cửa sổ: `max-width: calc(100% - 24px)` và `text-overflow: ellipsis` đảm bảo chip không làm vỡ layout hay phát sinh thanh cuộn ngang.

3. **Chuyển trang và khôi phục chỉ báo:**
   - Dùng nút Prev/Next chuyển sang trang 23: class `.citation-page-active` và chip tự động ẩn đi.
   - Bấm quay lại trang 22: viền và chip nguồn tự động hiển thị lại.
   - Bấm nút badge citation ở tin nhắn khác (ví dụ trang 15): nhảy đến trang 15, viền active bật và chip cập nhật thành `📖 Nguồn · Trang 15`.
   - Gửi câu hỏi mới: viền và chip nguồn lập tức ẩn đi cho đến khi lượt trả lời mới có citation.
