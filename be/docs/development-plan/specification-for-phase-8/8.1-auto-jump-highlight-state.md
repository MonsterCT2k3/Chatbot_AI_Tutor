# 8.1 — State `highlightedPage` + auto-jump trang khi citation

> Spec cho **agent implement**. Phase 7 đã xong: SSE gửi `citation` với `page_number`; FE đã **click badge → `setPageNumber`**. 8.1 thêm: (1) auto-jump khi citation **đầu** của lượt stream tới, (2) state trang đang cite dùng chung cho overlay ở **8.2**.

**Không** vẽ overlay CSS đầy đủ ở bước này (8.2). **Không** đụng `be/**`, bbox, RAG, SSE protocol.

## 2. Quyết định đã chốt (đừng để agent chọn lại)

| # | Chốt |
|---|---|
| 1 | State sống ở **`LessonWorkspacePage`**: `highlightedPage: number \| null` (mặc định `null`). |
| 2 | Một hàm helper ở page (tên gợi ý `revealCitationPage(page)`): `setPageNumber(page)` **và** `setHighlightedPage(page)`. Mọi citation UX (stream + click badge) gọi hàm này — **không** chỉ `setPageNumber` từ `ChatPanel` nữa. |
| 3 | Truyền vào `ChatPanel`: `revealCitationPage` (hoặc `onCitePage`). Có thể **bỏ** prop `setPageNumber` khỏi `ChatPanel` nếu không còn chỗ dùng — hoặc giữ nhưng citation **phải** đi qua `revealCitationPage`. |
| 4 | Truyền vào `SlideViewer`: `highlightedPage` (và vẫn `pageNumber` / `setPageNumber` cho nút prev/next thủ công). Prev/next **không** bắt buộc xoá `highlightedPage` (8.2 sẽ so `pageNumber === highlightedPage` để bật/tắt overlay). |
| 5 | **Auto-jump một lần / lượt hỏi:** trong `sendQuestion`, dùng `useRef` (vd. `didAutoJumpRef`) = `false` lúc bắt đầu gửi. Citation sau chỉ `push` vào bubble (như hiện tại), **không** nhảy thêm. |
| 6 | Click badge: `revealCitationPage(c.page_number)` (cập nhật cả page + highlight), kể cả khi đã auto-jump. |
| 7 | **Clear `highlightedPage = null`** khi: (a) bắt đầu `sendQuestion` (trước stream), (b) `onReplace` với `(citations || []).length === 0`, (c) `onError` / catch xoá bubble streaming, (d) đổi `documentId` (effect reset page đã có — thêm clear highlight), (e) đổi `sessionId` (không auto-jump lịch sử — clear highlight cho đỡ “dính” trang cite session cũ). |
| 8 | `onReplace` với citations **không rỗng**: cập nhật bubble như hiện tại; **đặt** `didAutoJumpRef` coi như đã jump; gọi `revealCitationPage(citations[0].page_number)` để khớp bản final (retry có thể đổi trang). |
| 9 | F5 / `listMessages`: **không** auto `revealCitationPage`. Click badge trên tin cũ vẫn gọi `revealCitationPage`. |

## 3. Thiết kế code

### 3.1 `LessonWorkspacePage.jsx`

```text
const [highlightedPage, setHighlightedPage] = useState(null);

function revealCitationPage(page) {
  const n = Number(page);
  if (!Number.isFinite(n) || n < 1) return;
  setPageNumber(n);           // SlideViewer đã clamp với numPages khi đổi tay;
                              // nếu muốn đồng bộ: clamp ở đây khi numPages đã có
  setHighlightedPage(n);
}

// Khi đổi documentId: đã setPageNumber(1) — thêm setHighlightedPage(null)
// Khi đổi sessionId: setHighlightedPage(null) (effect riêng hoặc chung)

<SlideViewer ... highlightedPage={highlightedPage} />
<ChatPanel ... revealCitationPage={revealCitationPage} />
// bỏ hoặc không dùng setPageNumber trên ChatPanel cho citation
```

Clamp: nếu `numPages` đã biết và `n > numPages`, clamp `1..numPages` trước khi set — tránh trang trắng. Nếu `numPages` còn null lúc citation sớm, vẫn `setPageNumber(n)`; viewer sẽ hiện khi PDF sẵn.

### 3.2 `ChatPanel.jsx`

Props: thêm `revealCitationPage`. Citation badge:

```text
onClick={() => revealCitationPage(c.page_number)}
```

Trong `sendQuestion`:

```text
didAutoJumpRef.current = false
revealCitationPage không gọi lúc start — chỉ clear highlight qua callback
  → cần prop onClearCitationHighlight?.() hoặc parent clear khi? 
```

**Chốt clear lúc gửi:** `ChatPanel` gọi `onClearCitationHighlight?.()` ở đầu `sendQuestion` **hoặc** page truyền `revealCitationPage` + `clearCitationHighlight`. Gọn nhất:

```text
// Page:
function clearCitationHighlight() { setHighlightedPage(null); }

// ChatPanel đầu sendQuestion:
clearCitationHighlight?.();
```

Không reset `pageNumber` về 1 khi gửi câu mới (user có thể đang xem trang nguồn — chỉ tắt “đang cite” cho đến citation mới).

`onCitation`:

```text
// push vào messages như hiện tại
if (!didAutoJumpRef.current && Number.isFinite(Number(citation.page_number)) && citation.page_number >= 1) {
  didAutoJumpRef.current = true;
  revealCitationPage(citation.page_number);
}
```

`onReplace`:

```text
// cập nhật messages như hiện tại
const next = citations || [];
if (next.length === 0) {
  clearCitationHighlight?.();
} else {
  didAutoJumpRef.current = true;
  revealCitationPage(next[0].page_number);
}
```

`onError` / `catch`: `clearCitationHighlight?.()` ngoài việc xoá bubble streaming.

`didAutoJumpRef`: `useRef(false)` trong `ChatPanel`.

### 3.3 `SlideViewer.jsx`

Thêm prop `highlightedPage = null`.

8.1 tối thiểu (chọn một):

- Gắn `data-citation-highlight={highlightedPage != null && highlightedPage === pageNumber ? '1' : '0'}` lên khung trang (vd. `.slide-canvas-card`), **hoặc**
- Class `citation-page-active` khi khớp — **chưa** cần style nổi (8.2 thêm CSS).

Prev/next vẫn `setPageNumber` — không đụng `highlightedPage`.

### 3.4 Sơ đồ luồng

```text
sendQuestion
  clearCitationHighlight()
  didAutoJumpRef = false
  ...
  onCitation #1  → push + revealCitationPage(p) + didAutoJump=true
  onCitation #2+ → push only
  onReplace []   → clearCitationHighlight
  onReplace [..] → revealCitationPage(first)
  click badge    → revealCitationPage(p)

LessonWorkspacePage
  pageNumber        → SlideViewer (trang đang xem)
  highlightedPage   → SlideViewer (trang đang được cite; 8.2 tô)
```
