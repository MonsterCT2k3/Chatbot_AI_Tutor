# 9.1 — FE đổi tên session (inline edit)

> Spec cho **agent implement**. Backend **đã có** `PATCH /api/sessions/{session_id}` body `{ "title": "..." }` (`SessionUpdate`, `min_length=1`, `max_length=200`, strip whitespace). FE hiện list / tạo / chọn / xoá session trong menu lịch sử `ChatPanel` — **chưa** gọi rename.

9.1 chỉ thêm UI + `renameSession` service. **Không** đụng SSE, citation, ingest.

---

## 0. Một câu

User đổi tên cuộc trò chuyện trong menu lịch sử (nút sửa hoặc double-click tiêu đề) → Enter lưu qua PATCH → title trên list + thanh session bar cập nhật.

| # | Chốt |
|---|---|
| 1 | API: `PATCH /sessions/{id}` + `{ title }` qua `apiClient` (envelope + 401 refresh sẵn). |

| 7 | Click một lần vào item = **chọn session** (như hiện tại). Nút bút / double-click **không** đổi session trừ khi đang chọn sẵn. Chốt: mở edit **không** bắt buộc `onSelectSession`; nếu muốn đồng bộ title bar chỉ khi đang active — OK. |
| 8 | Không đổi auto-title BE (câu đầu vẫn có thể đổi title lần đầu). User rename sau đó → title mới giữ cho tới khi rename lại. |
| 9 | Không làm rename từ thanh title ngoài menu (có thể làm sau) — **phạm vi 9.1 = trong history menu**. |

## 3. Thiết kế code

### 3.1 `sessionService.js`

```js
export async function renameSession(sessionId, title) {
  const { data } = await apiClient.patch(`/sessions/${sessionId}`, { title });
  return data; // SessionResponse sau envelope unwrap
}
```

### 3.2 `LessonWorkspacePage.jsx`

Truyền xuống `ChatPanel` callback kiểu:

```text
onRenameSession={async (id, title) => {
  const updated = await renameSession(id, title);
  setSessions((prev) => prev.map((s) => (s.id === id ? { ...s, ...updated } : s)));
  return updated;
}}
```

Hoặc ChatPanel gọi `renameSession` rồi `onSessionEnsured` / `onSessionsRefresh={listSessions}` — **chốt ưu tiên:** parent giữ source of truth `sessions`; callback `onRenameSession` như trên.

### 3.3 `ChatPanel.jsx`

State local:

```text
editingId: string | null
editTitle: string
renameBusy: boolean
```

Trong mỗi `li` history:

- Nút `Pencil` (lucide, size nhỏ) `title="Đổi tên"` → `editingId = s.id`, `editTitle = s.title || ''`, `stopPropagation`.
- Khi `editingId === s.id`: hiện `<input value={editTitle} ... />` thay cho title button (hoặc thay cả hàng title).
- Enter → `submitRename`; Esc → clear editing; blur → submit nếu hợp lệ else cancel.

`submitRename`:

```text
const t = editTitle.trim()
if (!t || t.length > 200) { cancel or clamp; return }
if (t === (session.title || '').trim()) { clear editing; return }
renameBusy=true
await onRenameSession(id, t)
clear editing
catch → setError('Không đổi được tên.') / giữ editing
finally renameBusy=false
```

Double-click trên `.chat-history-item-title`: cùng vào edit (`preventDefault` / không select session nếu có thể tách — nếu khó: double-click vẫn select + edit cũng chấp nhận được).

### 3.4 CSS

- Input gọn trong hàng list (font ~12–13px, width flex).
- Nút bút hiện khi hover hàng (desktop); mobile luôn hiện hoặc hiện cùng hàng với xoá — **chốt:** luôn hiện cạnh nút xoá (giống delete), không ẩn hết trên touch.

## 5. Test / DoD

1. Mở history → bấm bút trên một session → sửa title → Enter → list hiện tên mới; nếu đang active, thanh trên cũng đổi.
2. Refresh / `listSessions`: tên mới còn (đã PATCH DB).
3. Esc hoặc blur với chuỗi chỉ khoảng trắng: không gọi API / không title rỗng.
4. Title > 200: không 500; chặn hoặc trim client.
5. 404 session (xoá ở tab khác): hiện lỗi nhẹ, không crash.
6. Không regress: chọn session, tạo mới, xoá, gửi chat SSE.

### Kết quả đo

Đã xác minh qua build FE (`npm run build`) và test luồng trạng thái (`fe/src/scripts/test_9_1_rename.mjs`):

1. **Mở chế độ sửa tên (Inline Edit):**
   - Bấm nút icon bút (Pencil) bên cạnh item hoặc double-click vào tiêu đề session: hàng chuyển sang thẻ `<input>` với nội dung tiêu đề hiện tại được tự động focus và bôi đen toàn bộ.
   - Thao tác bấm nút bút không kích hoạt chuyển session ngoài ý muốn (`stopPropagation`).

2. **Lưu tiêu đề mới (Enter / Blur):**
   - Nhập tiêu đề mới (ví dụ: `Tìm hiểu kiến trúc Attention và Transformer`) và nhấn **Enter**: gọi API `PATCH /api/sessions/{id}` với payload `{ "title": "..." }`.
   - Sau khi lưu thành công, danh sách `sessions` cập nhật ngay lập tức. Nếu session đang được mở, tiêu đề trên thanh bar `chat-session-title` cũng đồng bộ đổi theo.

3. **Hủy chỉnh sửa (Escape / Blank Blur):**
   - Nhấn **Escape**: thoát khỏi chế độ edit, giữ nguyên tiêu đề ban đầu.
   - Xoá hết chữ (chỉ còn khoảng trắng) và blur ra ngoài: tự động huỷ chỉnh sửa, không gọi API với chuỗi rỗng.

4. **Xử lý biên & Giới hạn độ dài:**
   - Tiêu đề vượt quá 200 ký tự được tự động cắt đúng 200 ký tự ở client (`maxLength={200}` và `.slice(0, 200)`).
   - Các chức năng chọn session, tạo mới, xoá session và chat SSE tiếp tục hoạt động hoàn hảo không bị ảnh hưởng.
